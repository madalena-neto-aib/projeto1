O que é a maquilhagem?

A maquilhagem é uma forma de expressão pessoal que permite experimentar cores e diferentes estilos.

Produtos essenciais

  • Base ou corretor
  • Blush
  • Máscara de pestanas
  • Gloss ou batom
  • Paleta de sombras

Passos para uma maquilhagem simples

  1. Limpar e hidratar a pele
  2. Aplicar base ou corretor
  3. Aplicar blush
  4. Colocar máscara de pestanas
  5. Aplicar gloss ou batom
